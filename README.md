# Big Mart Sales Predictive WebApp

Welcome to the **Big Mart Sales Predictive WebApp** repository! This project is a data-driven web application designed to predict sales for Big Mart outlets using machine learning models. The application provides insights into sales trends, allowing for better business decision-making and planning.

## Features

- **Sales Prediction**: Predict sales for various Big Mart outlets based on key factors such as item type, outlet size, location type, and more.
- **User-Friendly Interface**: Built with an intuitive UI to make sales forecasting accessible to users with no coding experience.
- **Interactive Visualizations**: Gain deeper insights with charts and graphs showcasing sales trends.
- **Deployment**: Fully deployed as a web application for seamless accessibility.

## Technologies Used

- **Programming Language**: Python
- **Web Framework**: Streamlit
- **Machine Learning**: Scikit-learn, Pandas, NumPy
- **Visualization Tools**: Matplotlib, Seaborn, Plotly
- **Deployment**: Streamlit 

## Installation

To run the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Monisha09-ds/Big-Mart-Sales-Preditive-WebApp.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Big-Mart-Sales-Preditive-WebApp
   ```

3. **Install dependencies:**
   Ensure you have Python 3.7 or higher installed, then install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application:**
   ```bash
   streamlit run app.py
   ```

5. Open the link provided by Streamlit in your browser to use the application.

## Dataset

The dataset used for this project includes historical sales data from Big Mart outlets. It contains features such as:
- Item identifier
- Item weight
- Item visibility
- Item type
- Outlet identifier
- Outlet size
- Outlet location type
- Outlet type
- Item outlet sales (target variable)

## Usage

1. Upload the dataset or use the preloaded sample data.
2. Configure parameters and options for prediction.
3. View predictions, trends, and insights via the interactive dashboard.
4. Download results as a CSV file for further analysis.
